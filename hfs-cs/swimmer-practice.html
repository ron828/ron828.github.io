הורדת הפרויקט ל־Visual Studio

Visual Studio 2026 · .NET 10 · קובץ ZIP

מתחילים

  1. לחצו על כפתור ההורדה ושמרו את SwimmerPractice.zip במחשב.
  2. פתחו את סייר הקבצים ועברו לתיקייה שבה נשמר הקובץ — בדרך כלל הורדות (Downloads).
  3. לחצו קליק ימני על קובץ ה־ZIP ובחרו ״חלץ הכל…״ (Extract All...).
  4. בחלון שנפתח בחרו היכן לשמור את התיקייה, או השאירו את המקום המוצע, ולחצו ״חלץ״ (Extract). המתינו לסיום החילוץ.
  5. פתחו את התיקייה הרגילה שנוצרה לאחר החילוץ. בתוכה לחצו פעמיים על SwimmerPractice.sln כדי לפתוח את הפרויקט ב־Visual Studio.
  6. ב־Visual Studio פתחו את Program.cs ואת Swimmer.cs. הריצו עם Ctrl+F5; Main כבר מפעילה את Tests.RunAll().

פותחים את הפרויקט רק אחרי החילוץ. לחיצה כפולה על ה־ZIP מציגה את תוכנו, אבל אינה מחלצת את הפרויקט. אל תפתחו את ה־sln מתוך ה־ZIP, ואל תוציאו רק אותו: כל קובצי הפרויקט צריכים להישאר יחד בתיקייה שחולצה.

השלד מתקמפל גם לפני שמתחילים. בכל פעולה שטרם הושלמה יש שורת throw new NotImplementedException(...). כשמממשים את הסעיף, מסירים את שורת ה־throw שלו וכותבים את הקוד במקום המסומן. בפעולה שמחזירה ערך צריך להשלים גם return.

לא משנים את חתימות הפעולות ולא צריך לשנות את Tests.cs. בסעיפים 4 ו־10 יש שני חלקים; שניהם צריכים לעבוד כדי שהסעיף יעבור.

מערך דוגמה

כשנאמר בהמשך ״מערך הדוגמה״, הכוונה למערך הבא. הבדיקות יריצו את הפעולות גם על נתונים אחרים.

Swimmer[] swimmers = {
    new Swimmer("Noa", "backstroke", 29.4),

02

האם הסגנון זהה?

כותבים ב־Swimmer.cs · SameStyle

כתבו פעולה פנימית שמקבלת שחיין אחר, other, ומחזירה true אם הסגנון שלו זהה לסגנון של העצם המפעיל. אחרת תחזיר false.

public bool SameStyle(Swimmer other)

בדקו את הסגנון בלבד. השמות והזמנים יכולים להיות שונים. לדוגמה: שני שחייני freestyle יתאימו; שחיין freestyle ושחיין backstroke לא יתאימו.

הפעולה מחזירה תשובה באמצעות return; אין להדפיס בתוכה.

רמז קטן

בתוך Swimmer אפשר לגשת לתכונות של העצם המפעיל דרך this, ולתכונות של השחיין האחר דרך other. להשוואת מחרוזות כאן משתמשים ב־==.

05

סופרים שחיינים בסגנון נתון

כותבים ב־Program.cs · CountStyle

הפעולה מקבלת מערך שחיינים ואת הסגנון המבוקש בפרמטר style. החזירו כמה שחיינים במערך מתמחים בסגנון הזה.

public static int CountStyle(Swimmer[] swimmers, string style)

בשלד כבר נתונים מונה שמתחיל ב־0 ולולאה. השלימו את התנאי ואת הגדלת המונה. בסיום החזירו את המונה; אין להדפיס.

עבור מערך הדוגמה: חיפוש "freestyle" יחזיר 2, חיפוש "backstroke" יחזיר 1, וחיפוש "butterfly" יחזיר 0.

השתמשו בפרמטר style: הפעולה צריכה לעבוד עבור כל אחד מארבעת הסגנונות.

רמז קטן

06

מוצאים את הזמן הטוב ביותר

כותבים ב־Program.cs · BestRecord

בתרגיל הזה כל השחיינים במערך מתמחים באותו סגנון. החזירו את הזמן הנמוך ביותר במערך, מסוג double.

public static double BestRecord(Swimmer[] swimmers)

בשלד כבר נשמר הזמן של השחיין הראשון במשתנה best, והלולאה מתחילה בתא 1. בכל סיבוב החליטו אם צריך לעדכן את best. בסיום החזירו אותו.

גם מערך עם שחיין אחד הוא קלט תקין: במקרה כזה מחזירים את הזמן שלו. אין צורך לטפל במערך ריק.

רמז קטן

הזמן הנמוך ביותר הוא הטוב ביותר. חפשו זמן קטן מ־best; אין לאתחל את best לאפס.

כותבים ב־Program.cs · FastestName

גם כאן כל השחיינים באותו סגנון, ויש שחיין אחד שזמנו נמוך משל כל האחרים. כתבו פעולה שמחזירה את שמו.

public static string FastestName(Swimmer[] swimmers)

הפעם נתונה רק החתימה. היעזרו ברעיון מתרגיל 6, אבל שמרו גם דרך להגיע לשחיין בעל השיא — למשל אינדקס, או הפניה לעצם. כשנמצא זמן טוב יותר, עדכנו את השחיין שנבחר.

לדוגמה: עבור A: 28.9, B: 28.1, C: 28.6 באותו סגנון, התוצאה היא "B", ולא 28.1. הפעולה מחזירה שם ואינה מדפיסה אותו.

08

בוחרים את המהיר בסגנון המבוקש

כותבים ב־Program.cs · FastestInStyle

כעת המערך מכיל סגנונות שונים. הפעולה מקבלת גם style, ומחזירה את שם השחיין בעל הזמן הנמוך ביותר מבין השחיינים בסגנון המבוקש בלבד.

public static string FastestInStyle(Swimmer[] swimmers, string style)

בסעיף הזה אפשר להניח שקיים לפחות שחיין אחד בסגנון המבוקש ושיש ביניהם בעל שיא יחיד.

  1. נקודת התחלה: כתבו חיפוש של השחיין הראשון בסגנון המתאים. שמרו את מיקומו או את ההפניה אליו.
  2. שיפור הבחירה: עברו על שאר השחיינים. החליפו את הבחירה רק כשגם הסגנון מתאים וגם הזמן טוב יותר.
  3. החזירו את שם השחיין שנבחר.
רמז קטן

השחיין שבתא 0 לא בהכרח מתאים. תחילה צריך למצוא מועמד בסגנון המבוקש; רק אז אפשר להשוות אליו זמנים.

09

מוסיפים מקרה של אין התאמה

כותבים ב־Program.cs · FastestNameOrEmpty

כתבו פעולה נוספת עם אותה מטרת חיפוש. הפעם ייתכן שאין במערך אף שחיין בסגנון המבוקש.

public static string FastestNameOrEmpty(Swimmer[] swimmers, string style)

אם קיימת התאמה, החזירו את שם השחיין המהיר ביותר בסגנון הזה. אם אין התאמה, החזירו מחרוזת ריקה: "". אין להדפיס הודעה מתוך הפעולה.

אפשר להיעזר ב־CountStyle וב־FastestInStyle שכבר כתבתם. שמרו את הפעולה מתרגיל 8 והשלימו את הפעולה החדשה במקומה המסומן.

למשל, מערך הדוגמה אינו מכיל שחיין butterfly, ולכן עבור סגנון זה יוחזר "". המערך עצמו עדיין אינו ריק.

רמז קטן

אם אין אף שחיין מתאים, אין מועמד שאת שמו אפשר להחזיר. אם יש התאמה, כבר כתבתם פעולה שמבצעת את החיפוש.
